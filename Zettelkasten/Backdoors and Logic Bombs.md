# Backdoors and Logic Bombs

## Resumo

Backdoor usado para transpassar a autenticação de sistemas um Remote Access Trojan é um backdoor

Logic Bomb é um código malicioso inserido em um programa e irá ser executado somente em certas condições, por exemplo um funcionário insatisfeito pode inserir uma logic bomb

## Flashcards

O que é uma Logic Bomb?
?
Código malicioso que só será executado se atingir certas condições
