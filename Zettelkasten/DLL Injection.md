# DLL Injection

## Resumo

DLL Injection é uma técnica de ataque onde um processo malicioso **força um processo legítimo a carregar e executar uma DLL(Dynamic Link Library) maliciosa**. O objetivo principal é executar código malicioso com os privilégios de um processo confiável, contornando defesas como antivírus e firewalls.
