# Diversion Theft

## Resumo

Roubo por desvio - Definição, envolve a manipulação de uma situação ou a a criação de uma distração(decoy) para roubar itens ou informações valiosas.

Um DNS Spoofing Attack, o atacante manipula o DNS de modo que, quando um usuário digita o URL de um site legítimo, ele é redirecionado para um site falso criado pelo invasor.
