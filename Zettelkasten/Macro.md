# Macro

## Resumo

São uma forma de código que permite que um vírus seja incorporado em outro documento, para que, quando esse documento for aberto pelo usuário o vírus seja executado

## Flashcards

O que é um vírus do tipo Macro?
?
Código malicioso embedded(incorporado) em um documento. Exemplos:

- xlsx
- ppt
