# Technical Controls

## Resumo

Technical Controls - Definição, são as tecnologias, os mecanismos de hardware e software implementados para gerenciar e reduzir os riscos. - Eles operam em uma camada de tecnologia de sistemas

## Síntese ou Insight Pessoal

Exemplo: - Um antivírus instalado que sempre verifica um arquivo baixado, ou seja é governada pelo próprio sistema. - Firewalls - Encryption Processes - Intrusion Detection Systems
