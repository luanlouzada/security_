# Encrypted

## Resumo

É projetado para se esconder da detecção, criptografando seu código malicioso ou payloads para evitar detecção por um antivírus

## Flashcards

O que é um Encrypted Virus?
?
É projetado para se esconder da detecção, criptografando seu código malicioso ou payloads para evitar detecção por um antivírus, **NÃO** confunda com Ransomware
