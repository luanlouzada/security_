# Security Guards

## Resumo

Pessoal treinado para **detecção ativa**, **resposta imediata** e **presença dissuasora**. Complementam controles técnicos com **avaliação de risco in loco**, verificação de alarmes, patrulhas e controle de acesso. Importante para **procedimentos**, **relatórios de incidentes** e interação humana durante emergências.
