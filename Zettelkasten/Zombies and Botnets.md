# Zombies and Botnets

## Resumo

Botnet é uma rede de computadores ou dispositivos comprometidos, são usados para ataques cibernéticos como DDOS

Zombies é simplesmente o nome de um computador ou dispositivo comprometido que faz parte de uma botnet

###### Command and Control Node

Responsável por gerenciar o controle do invasor, conhecido como **nó C2**, podem fazer um ataque a partir do computador da vítima para se camuflar
