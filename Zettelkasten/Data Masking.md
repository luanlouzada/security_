Mascaramento de dados

- Definição, método que envolve obscurecimento de dados específicos em um banco de dados para torná-los inacessíveis a usuários não autorizados, mantendo a autenticidade e o uso dos dados reais para usuários autorizados.
- Exemplo: Se uma máquina de cartão de crédito armazena o número do cartão do usuário, pode usar o mascaramento para que os primeiros 12 dígitos do número sejam mascarados
