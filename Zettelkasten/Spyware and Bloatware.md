# Spyware and Bloatware

## Resumo

**Spyware**, software malicioso que enviam informações sobre um usuário ou organização sem o conhecimento, hábitos de navegação, até senhas e números de cartão de crédito

Importante ler o EULA(end-user licensing agreement) para ver se está coletando dados pessoais ou privados

**Bloatware** refere-se a qualquer software que vem pré-instalado em seu novo computador, que você como usuário não solicitou, não é danoso, mas ocupado espaço ou uso de memória ram
