# Program

## Resumo

Tentam encontrar executáveis ou arquivos de aplicativos para infectar com seu código malicioso.

Exemplo: Se você abriu acidentalmente um vírus de programa enquanto navegava na internet, ele pode tentar se instalar em um dos seus programas como Microsoft Word que já está instalado no computador, assim toda vez que abrir ele reinfecta seu computador

## Flashcards

O que é um Program Virus?
?
Vírus que tenta achar um aplicativo ou arquivo para infectar, assim toda vez que você o abre como um word ele reinfecta seu computador
