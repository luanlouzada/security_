# Compensating Controls

## Resumo

Controles de Compensação - Definição, medidas alternativas implementadas quando os controles de segurança primários simplesmente não são viáveis ou eficazes - Exemplo: Executando um sistema legado que simplesmente não é compatível com a forma mais recente de criptografia sem fio conhecida como WPA3, usar uma WPA2 + VPN (Isso é um controle de compensação)
