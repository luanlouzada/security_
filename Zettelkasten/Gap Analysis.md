# Gap Analysis

## Resumo

Análise de Lacunas - Definição, processo de avaliação das diferenças entre o desempenho de uma organização e o desempenho desejado.

1. Definir o escopo de análise.
2. Coletar dados do estado atual da organização.
3. Analisar os dados para identificar os gaps
4. Desenvolver um plano para preenchê-las

Ao compreender a gravidade de cada descoberta criamos um [[Plan of Action and Milestones (POA&M)]]
