# Outsmarting Threat Actors

## Resumo

Sendo mais esperto que os agentes de ameaça - Utilizar tecnologias de engano e interrupção, como honeypots, honeynets, honeyfiles, honeytokens, assim aprendemos seus ataques e procedimentos - O conjunto de táticas técnicas e procedimentos usados são chamados de **Type Adversary(TTPS(Tactics, Techniques and Procedures))** - Algumas interrupções podem ser feitas usando bogus **DNS entries(DNS FALSOS)**, diretórios falsos, gerando páginas dinâmicas para tornar os web crawlers mais lentos, **uso de acionamento de portas para serviços falsos(port triggering)** usando spoofing fake telemetry data, dados de telemetria falsos para uma varredura de rede detectada

## Flashcards

O que significa TTPS?
?
Tactics, Techniques and Procedures usados por Threat Actors

Quais são algumas técnicas de interrupção usadas para enganar e atrasar agentes de ameaça?  
?  
Algumas técnicas incluem o uso de **DNS FALSOS** (bogus DNS entries), **diretórios falsos**, geração de **páginas dinâmicas** para tornar web crawlers mais lentos, **acionamento de portas para serviços falsos** (port triggering) e o envio de **dados de telemetria falsos** para uma varredura de rede.
