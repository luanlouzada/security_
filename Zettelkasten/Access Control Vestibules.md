# Access Control Vestibules

## Resumo

Área de controlo de acesso (vestíbulo) com **duas portas** sequenciais para controlar entrada/saída e prevenir following (tailgating). Utilizada para **verificação de identidade**, controle de fluxo e como barreira física adicional.
