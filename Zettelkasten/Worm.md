# Worm

## Resumo

Software mal intencionado, parecido como o vírus, mas consegue se replicar sem nenhuma intervenção do usuário

O Worm se aproveita de falhas de segurança e usa essa vulnerabilidade para se espalhar.

Podem causar interrupções no tráfego normal da rede, pois estão constantemente tentando se replicar e se espalhar pela rede. Isso começa a consumir não apenas nossos recursos de rede, **mas também consome potência de computação, CPU, MEM, IO**

Dessa forma **pode se parecer como DoS Attack**

## Flashcards

Qual a diferença de um Worm para um Virus?
?
O virus depende do usuário executar, como abrir um arquivo, o worm pode se replicar e se espalhar pela rede.
