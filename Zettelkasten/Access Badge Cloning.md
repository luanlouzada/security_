# Access Badge Cloning

## Resumo

Clonagem de badges ocorre quando atacantes **copiam** credenciais RFID/NFC ou códigos de cartão para criar cópias não autorizadas. Mitigações: **badges com criptografia**, **controle multifatorial**, **monitoramento de uso anômalo**, e **rotatividade de credenciais**.
